# MHSDEV01 - Portfolio

Este repositório contém o código fonte do meu portfolio pessoal desenvolvido com React, TypeScript e Vite.

## Tecnologias Utilizadas

- React
- TypeScript
- Vite
- CSS Modules
- i18n (Internacionalização)

## Funcionalidades

- Design Responsivo
- Tema Claro/Escuro
- Suporte a múltiplos idiomas (Português, Inglês, Espanhol)
- Seções: Sobre, Serviços, Projetos, Contato

## Estrutura do Projeto

O código fonte principal encontra-se na pasta `portfolio`.

## Como executar

1. Navegue até a pasta do projeto:
   ```bash
   cd portfolio
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
